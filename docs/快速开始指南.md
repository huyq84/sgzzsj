# 建筑工程施工组织设计系统 - 快速开始指南

## 🚀 系统简介

建筑工程施工组织设计系统是一个基于AI技术的智能设计平台，能够根据用户提供的项目资料自动生成高质量的施工组织设计文档。

### ✨ 主要特性
- 🤖 AI智能分析文档和图纸
- 🏗️ 支持多专业（建筑、结构、机电、装饰）
- 📋 双模式设计（投标阶段、施工阶段）
- 📁 完整的文档管理系统
- 👥 多用户协作支持
- 🔒 安全的权限管理

## 📋 系统要求

### 硬件要求
- CPU: 4核心以上
- 内存: 8GB以上
- 存储: 20GB可用空间
- 网络: 稳定的互联网连接

### 软件要求
- Docker 20.10+
- Docker Compose 2.0+
- Git

## 🛠️ 安装步骤

### 1. 克隆项目
```bash
git clone <项目地址>
cd construction-design-system
```

### 2. 配置环境变量
```bash
# 复制环境变量模板
cp .env.example .env

# 编辑环境变量文件
nano .env
```

**重要配置项：**
```env
# OpenAI API密钥（必需）
OPENAI_API_KEY=your-openai-api-key-here

# 数据库配置
DATABASE_URL=postgresql://admin:password123@postgres:5432/construction_design

# JWT密钥（建议修改）
SECRET_KEY=your-secret-key-here
```

### 3. 启动系统
```bash
# 使用启动脚本（推荐）
./start.sh

# 或手动启动
docker-compose up -d
```

### 4. 等待服务启动
系统启动需要几分钟时间，请耐心等待。可以通过以下命令查看服务状态：
```bash
docker-compose ps
```

## 📖 使用指南

### 1. 用户登录
1. 访问 http://localhost
2. 使用默认账户登录
3. 首次登录建议修改密码

### 2. 创建项目
1. 点击"项目管理" → "新建项目"
2. 填写项目基本信息：
   - 项目名称
   - 项目类型（住宅、商业、工业等）
   - 建筑类型（框架、剪力墙、钢结构等）
   - 建筑面积、楼层数等
3. 保存项目

### 3. 上传文档
1. 进入项目详情页
2. 点击"文档管理" → "上传文档"
3. 支持的文件类型：
   - PDF文档（投标文件、技术规范等）
   - CAD图纸（.dwg格式）
   - Word文档（.docx格式）
   - Excel表格（.xlsx格式）
   - 图片文件（.jpg, .png格式）

### 4. 生成施工组织设计
1. 点击"设计生成器"
2. 选择设计类型：
   - **投标阶段**: 适用于投标时的施工组织设计
   - **施工阶段**: 适用于实际施工时的详细设计
3. 选择专业类型（建筑、结构、机电、装饰）
4. 选择设计模板
5. 点击"开始生成"

### 5. 查看和下载设计
1. 生成完成后，可以在"我的设计"中查看
2. 支持在线预览和下载PDF格式
3. 可以编辑和重新生成设计

## 🔧 常见问题

### Q: 系统启动失败怎么办？
A: 检查以下几点：
1. Docker和Docker Compose是否正确安装
2. 端口是否被占用（80, 8000, 8001, 5432, 6379, 9000, 9001）
3. 环境变量文件是否正确配置

### Q: AI功能无法使用？
A: 确保：
1. OpenAI API密钥已正确配置
2. 网络连接正常
3. API密钥有足够的额度

### Q: 文件上传失败？
A: 检查：
1. 文件大小是否超过100MB
2. 文件格式是否支持
3. 存储空间是否充足

### Q: 数据库连接失败？
A: 尝试：
1. 重启数据库服务：`docker-compose restart postgres`
2. 检查数据库日志：`docker-compose logs postgres`
3. 重新初始化数据库
