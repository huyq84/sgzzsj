# 建筑工程施工组织设计系统

一个专业的建筑工程施工组织设计管理系统，支持智能生成投标阶段和施工阶段的施工组织设计文档。

## 🚀 系统特性

### 核心功能
- **项目管理**: 完整的项目生命周期管理
- **智能生成**: 基于模板和项目信息自动生成施工组织设计
- **模板管理**: 可自定义的施工组织设计模板
- **文档管理**: 统一的文档存储和版本控制
- **团队协作**: 多用户权限管理和协作编辑
- **进度跟踪**: 实时项目进度监控

### 技术特色
- **现代化架构**: React + Node.js + MongoDB
- **响应式设计**: 支持桌面和移动端访问
- **权限控制**: 基于角色的访问控制(RBAC)
- **文件处理**: 支持多种格式文档上传和解析
- **模板引擎**: 基于Handlebars的智能内容生成

### 🔬 专业性和严谨性保证

#### 1. **标准规范库支撑**
系统内置完整的建筑工程标准规范库，包括：
- **国家标准**: GB系列标准（如GB 50010混凝土结构设计规范）
- **行业标准**: JGJ、CJJ等行业规范
- **地方标准**: 各省市地方标准规范
- **企业标准**: 可自定义企业内部标准

**数据来源严谨性**：
- 所有标准规范均来自官方发布的现行有效版本
- 定期更新废止和修订的标准
- 专家审核验证标准内容的准确性
- 建立标准规范的引用关系和适用条件

#### 2. **专业知识库体系**
建立多层次的专业知识库：
- **施工工艺库**: 详细的施工方法和操作规程
- **质量控制库**: 质量控制要点和检验标准
- **安全措施库**: 安全技术措施和应急预案
- **技术方案库**: 成熟的技术解决方案
- **案例研究库**: 真实工程案例和经验总结

**知识质量控制**：
- 专家评审机制，每个知识条目都经过专业人员审核
- 知识来源可追溯，标注参考文献和标准依据
- 定期更新和维护，确保知识的时效性
- 用户反馈和评分系统，持续优化知识质量

#### 3. **智能生成的专业算法**
- **上下文分析**: 根据项目类型、规模、地域等因素智能匹配相关标准和知识
- **适用性判断**: 自动判断标准规范和技术方案的适用条件
- **内容关联**: 建立知识间的关联关系，确保生成内容的完整性和一致性
- **质量评估**: 对生成内容进行质量评分和置信度计算

#### 4. **多层次质量控制机制**

**输入质量控制**：
- 项目信息完整性检查
- 关键参数合理性验证
- 强制性标准条文的自动应用

**生成过程控制**：
- 标准规范自动引用和检查
- 技术方案可行性分析
- 安全措施完备性验证
- 质量控制要点覆盖检查

**输出质量保证**：
- 生成文档的规范性检查
- 引用标准的有效性验证
- 技术内容的逻辑性检查
- 专业术语的准确性校验

#### 5. **专家审核体系**
- **分级审核**: 初审、复审、终审三级审核机制
- **专业分工**: 按专业领域分配审核专家
- **审核标准**: 建立统一的审核标准和评分体系
- **持续改进**: 根据审核反馈持续优化生成算法

## 🚀 快速开始

### 1. 克隆项目
```bash
git clone <repository-url>
cd construction-organization-system
```

### 2. 自动安装和配置
```bash
chmod +x start.sh
./start.sh
```

### 3. 环境配置
复制并配置环境变量文件：
```bash
cp .env.example .env
```

编辑 `.env` 文件，配置以下关键参数：
```env
# 数据库配置
MONGODB_URI=mongodb://localhost:27017/construction_system

# JWT密钥（生产环境请使用强密码）
JWT_SECRET=your_super_secret_jwt_key_here

# 服务器配置
PORT=5000
NODE_ENV=development
CLIENT_URL=http://localhost:3000
```

### 4. 初始化专业数据库
```bash
# 运行数据初始化脚本
node scripts/initializeStandardsData.js
```

### 5. 启动系统

#### 开发模式（推荐）
```bash
npm run dev
```

#### 分别启动前后端
```bash
# 终端1 - 启动后端
npm run server

# 终端2 - 启动前端
npm run client
```

#### 生产模式
```bash
npm run build
npm start
```

### 6. 访问系统
- 前端地址: http://localhost:3000
- 后端API: http://localhost:5000/api

## 🔧 开发指南

### API接口文档
系统提供RESTful API接口，主要端点包括：

```
POST /api/auth/login          # 用户登录
POST /api/auth/register       # 用户注册
GET  /api/projects           # 获取项目列表
POST /api/projects           # 创建新项目
GET  /api/projects/:id       # 获取项目详情
POST /api/projects/:id/generate  # 生成施工组织设计
GET  /api/templates          # 获取模板列表
POST /api/files/upload       # 上传文件
GET  /api/standards          # 获取标准规范
GET  /api/knowledge          # 获取专业知识
```

### 数据库设计
系统使用MongoDB存储数据，主要集合包括：
- `users` - 用户信息
- `projects` - 项目信息
- `templates` - 模板信息
- `documents` - 文档信息
- `standardslibraries` - 标准规范库
- `knowledgebases` - 专业知识库

### 扩展开发
要添加新功能，请遵循以下步骤：
1. 在 `models/` 中定义数据模型
2. 在 `routes/` 中创建API路由
3. 在 `client/src/pages/` 中创建前端页面
4. 在 `client/src/services/` 中添加API调用

## 🎯 专业性保证措施

### 数据来源可靠性
1. **官方标准**: 所有标准规范均来自国家和行业主管部门发布的官方版本
2. **专家验证**: 建立专家委员会，对关键内容进行专业审核
3. **持续更新**: 定期跟踪标准规范的更新和修订情况
4. **来源追溯**: 每个知识条目都标注数据来源和参考依据

### 质量控制体系
1. **多级审核**: 建立初审、复审、终审的三级审核机制
2. **专业分工**: 按照专业领域分配相应的审核专家
3. **质量评分**: 建立知识条目的质量评分和信誉度体系
4. **用户反馈**: 收集用户使用反馈，持续改进内容质量

### 技术保障措施
1. **智能匹配**: 根据项目特征智能匹配相关标准和技术方案
2. **适用性检查**: 自动检查标准规范和技术方案的适用条件
3. **完整性验证**: 确保生成的施工组织设计内容完整、逻辑清晰
4. **一致性校验**: 检查不同章节内容的一致性和协调性
